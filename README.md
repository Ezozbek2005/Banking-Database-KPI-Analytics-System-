Banking Database & KPI Analytics System
Overview

This project simulates a real-world banking database system designed for analytics and reporting.

The system contains 30+ relational tables and supports banking operations, customer management, transactions, and KPI reporting.

Monthly transactions

Example KPIs
Total Transaction Volume
SELECT SUM(Amount)
FROM Transactions
Active Customers
SELECT COUNT(*)
FROM Customers
WHERE Status = 'Active'
Monthly Revenue
SELECT MONTH(TransactionDate), SUM(Amount)
FROM Transactions
GROUP BY MONTH(TransactionDate)
